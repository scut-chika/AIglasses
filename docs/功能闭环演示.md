- 初赛阶段以网页端（app/）演示 Agent 的真实运行：接入用户自备的 AI 服务 Key，打开浏览器即可复现全部闭环

## 场景一：清晨 08:00 · 忘记吃降压药（主动提醒闭环）

**场景描述**

王奶奶，68 岁，独居。周一早上 8 点，她坐在床边发呆，完全不记得该吃降压药了。女儿在外地，最担心的就是这件事。

**使用过程（对话与 Agent 运行）**

| 时间 | 发生的事 | 老人 / 系统 | Agent 决策轨迹 |
| --- | --- | --- | --- |
| 08:00 | 用药时间到 | 系统主动开口："王奶奶，该吃降压药了。" | [触发] 时间触发 · 用药计划（HIGH）→ [工具] 用药计划 → [反馈] 提醒 |
| 08:02 | 老人去拿药 | 老人："好，我这就吃。" 系统："看到您拿着降压药了，吃完跟我说一声。" | [感知] 场景=餐厅 · 可见=降压药药盒 → [工具] 视觉确认 |
| 08:04 | 老人服完药 | 老人："吃完了。" 系统："好的，已记录您这次服药。" | [理解] 意图=确认服药 → [工具] 健康日志 → [记忆] 服药记录写入 |

**异常分支**

- 10 分钟未确认 → 震动 + 再次提醒
- 30 分钟仍未确认 → 通知子女"今早 8 点降压药可能漏服"

**解决方案价值**

把"提醒"升级为"确认 + 记录 + 家人联动"：不仅提醒吃药，还确认真的吃了，并让异地子女心里有底。

## 场景二：上午 09:30 · 找不到老花镜（记忆找物闭环）

**场景描述**

上午九点半，王奶奶想在沙发上看报纸，却怎么也找不到老花镜，翻遍三个抽屉急得团团转。

**使用过程**

| 时间 | 发生的事 | 老人 / 系统 | Agent 决策轨迹 |
| --- | --- | --- | --- |
| 09:30 | 老人求助 | 老人："我的老花镜呢？" | [理解] 意图=找物 · 目标=老花镜 → [工具] 记忆库检索 |
| 09:30 | 眼镜回答 | 系统："老花镜在客厅茶几上，我上次看到是下午两点半。" | [工具] 记忆库检索 → 命中（置信度 0.9）→ [反馈] 语音回答 |
| 09:31 | 老人找到 | 老人："找到了！" 系统："太好了，我记下了。" | [感知] 可见=老花镜 → [记忆] 复核更新（置信度↑） |

**异常分支**

记忆未命中时，眼镜会现场扫描高频区域，找到后回写记忆；没有把握时明确告知，不编造位置。

**解决方案价值**

第一视角记忆让"随问随答"成为可能，且越用越准——这是手机和手表做不到的。

## 场景三：下午 16:00 · 出门买菜忘带伞、忘关火（出门提醒闭环）

**场景描述**

下午四点多，外面下着雨。王奶奶准备出门买菜，走到门口时，厨房灶台上还炖着汤。

**使用过程**

| 时间 | 发生的事 | 老人 / 系统 | Agent 决策轨迹 |
| --- | --- | --- | --- |
| 16:05 | 走到门口 | 系统主动开口："外面在下雨，带伞；厨房火好像还开着，要回去看一眼吗？" | [触发] 场景触发 · 走向门口 → [工具] 天气 API + 室内状态记忆 |
| 16:07 | 返回关火 | 老人："火关了。" 系统："火已经关了，可以放心出门。" | [感知] 场景=厨房 → [工具] 视觉确认 → [记忆] 室内状态更新 |
| 16:10 | 再次出门 | 系统只提醒天气："带伞。" | [记忆] 已确认关火，不再重复唠叨 |

**异常分支**

出门 30 分钟未归且无记录 → 家人低打扰通知。

**解决方案价值**

多源信息联动（天气 + 室内状态）在出门前一句话给出，主动守护且不唠叨。

## 场景四：晚上 20:00 · 子女远程安心（健康日报闭环，App 形态规划）

**场景描述**

晚上八点，王奶奶的女儿结束加班，想知道妈妈今天过得怎么样——但她不想打电话"盘问"，怕妈妈嫌烦。

**解决方案**

每晚 8 点，子女端 App 自动收到一条日报：

- 一切正常："今天都挺好：服药 ✓ · 出门 1 次 · 无异常事件"
- 有异常时展开详情：漏服提醒、跌倒事件、深夜未归等

**价值**

低打扰守护：正常不打扰，异常才提醒；子女从"焦虑追问"变成"安心确认"。

## 场景五：深夜 23:30 · 跌倒求助（安全守护闭环，V2 规划）

**场景描述**

深夜，王奶奶起夜时在卧室跌倒，无法起身，身边没有手机。

**解决方案**

1. 眼镜 IMU 检测到姿态突变 + 视觉确认人形倒地（双通道，降低误报）
2. 语音二次确认："王奶奶，您摔着了吗？需要帮忙吗？"
3. 老人没有回应（15 秒）→ 自动呼叫紧急联系人，附定位 + 第一视角快照
4. 事件写入健康日志；误报样本用于模型迭代

**价值**

把"黄金救援时间"真正用起来——跌倒后无人知晓是独居老人最大的风险之一。
