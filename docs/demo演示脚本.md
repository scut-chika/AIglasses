# 暖眸 Demo 演示脚本（视频约 5 分钟）

## 0. 演示方案（初赛：Agent 真实运行录屏）

**推荐形式：真实 Agent 运行录屏（app/，填入自己的 AI Key 后真实运行）**

* 主画面：浏览器操作 app/ 前端，演示三个闭环的真实运行过程
* 录屏范围：配置页（填 Key → 保存 → 测试连接）→ 摄像头 / 场景输入 → 三个闭环逐步运行 → 决策轨迹 → 记忆面板变化
* 叠加：画外音讲解 + 字幕；浏览器语音朗读 Agent 反馈，体现语音交互
* **加分点**：Agent 真实运行（真实 LLM、真实工具、真实记忆），评委可用 GitHub 链接自行复现
* **无 Key 兜底**：用 web/ 概念演示版（无需 Key）录屏；断网时可直接双击 web/index.html 运行
* **产品形态说明**：视频开头或结尾需说明——网页端为初赛演示形态，正式产品为「AI 眼镜 + 老人端 App + 子女端 App」

## 1. 准备清单

| 类别 | 物品 |
| --- | --- |
| 设备 | 电脑 + Chrome / Edge 浏览器 + 自己的 AI 服务 Key |
| 人员 | 操作者（可兼任画外音） |
| 软件 | app/ 真实版（py server.py 启动）、录屏工具（OBS / 系统录屏）、剪辑软件 |

**拍摄提示**

* 建议 Chrome/Edge，浏览器语音识别与朗读最稳定
* 录制前先用真实 Key 完整跑一遍三个闭环，确认服务商接口正常
* 每步停留在"反馈"轨迹上 1–2 秒，穿插记忆面板变化特写（如服药记录写入）
* 无 Key 或断网时，使用 web/ 概念演示版录屏兜底

## 2. 分镜脚本

### 幕 0 · 痛点引入（40 秒）

**画面**：王奶奶一天的蒙太奇——找老花镜翻了三个抽屉、桌上药盒没动、手机铃响是女儿来电。

**画外音**："68 岁的王奶奶独居。记性越来越差——眼镜放哪了、药吃了没，成了每天最大的事。女儿不在身边，只能靠打电话确认。"

**字幕**：独居老人 · 遗忘 · 安全 · 孤独

### 幕 1 · 找物闭环（90 秒）

| 镜头 | 画面 | 台词 | 画中画（Agent 决策） |
| --- | --- | --- | --- |
| 1.1 | 第一视角：王奶奶在客厅翻找 | 奶奶：我的老花镜呢？ | 感知：语音 ASR → 意图=找物（老花镜） |
| 1.2 | 画中画放大决策框 | 暖眸：老花镜在客厅茶几上，下午两点半我见您放在那。 | 工具：记忆库检索 → 命中（置信度 0.9） |
| 1.3 | 奶奶走向茶几找到眼镜 | 奶奶：找到了！ | 视觉复核 → 记忆更新 |

**字幕**：第一视角记忆 —— 看过即记住，随问随答

### 幕 2 · 用药提醒（120 秒，主动 Agent 核心段）

| 镜头 | 画面 | 台词 | 画中画 |
| --- | --- | --- | --- |
| 2.1 | 第一视角：早上，奶奶在卧室 | 暖眸（主动）：王奶奶，该吃降压药了。 | 触发：时间触发 08:00 用药计划（HIGH）→ 决策：主动开口 |
| 2.2 | 奶奶走向餐桌拿起药盒 | 奶奶：好，我这就吃。 暖眸：看到您拿着降压药了，吃完跟我说一声。 | 感知：视觉识别药盒 → 确认中 |
| 2.3 | 奶奶喝水服药 | 奶奶：吃完了。 | 工具：健康日志写入服药记录 |
| 2.4 | 手机画面：女儿收到提示 | 女儿：今天药吃了，我就放心了。 | 通知：漏服升级机制说明（10 分钟/30 分钟） |

**字幕**：主动提醒 + 视觉确认 —— 不是问答，是守护

### 幕 3 · 出门提醒（60 秒）

| 镜头 | 画面 | 台词 | 画中画 |
| --- | --- | --- | --- |
| 3.1 | 第一视角：奶奶走向门口，窗外下雨 | 暖眸（主动）：外面在下雨，带伞；厨房火好像没关，要回去看一眼吗？ | 触发：场景触发 走向门口 → 工具：天气 API + 室内状态记忆 |
| 3.2 | 奶奶返回关火，回到门口 | 暖眸：火已经关了，可以放心出门。 | 视觉确认 → 记录出门时间 |

### 幕 4 · 家人日报（30 秒）

**画面**：手机收到推送——"今天都挺好：服药 ✓ · 出门 2 次 · 无异常事件"。

**画外音**："一切正常时，家人只收到一句'今天都挺好'。低打扰，才是长期陪伴。"

### 幕 5 · 收尾（30 秒）

**画面**：一页技术架构图（感知 → 情境 → Agent → 工具 → 反馈 → 记忆）+ 产品形态图（Web 演示 → 眼镜 + 老人端 App + 子女端 App）+ 合规要点（本地优先、可删除、不做诊断）。

**画外音**："暖眸——看得见、记得住、靠得住。网页端是初赛演示形态；正式产品将落地为 AI 眼镜 + 老人端 App + 子女端 App，下一阶段加入跌倒求助与健康体征监测。"
