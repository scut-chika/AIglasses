# 暖眸 · Web 演示前端（初赛用）

**无需硬件、无需后端、无需安装依赖**。浏览器直接打开 `index.html`
即可演示三个闭环的 Agent 功能；也可以部署到静态托管生成在线链接，
录屏即可作为初赛演示视频。

## 本地运行

方式一：双击打开 `web/index.html`。

方式二（推荐，可用浏览器 TTS 语音朗读）：

```powershell
cd web
python -m http.server 8000
```

然后访问 http://localhost:8000 ，建议使用 Chrome / Edge。

## 功能

* 三个闭环场景一键切换：记忆找物 / 用药提醒 / 出门提醒
* 逐步演示：上一步 / 下一步 / 自动播放（键盘 ← → 也可控制）
* Agent 决策轨迹实时展示：感知 → 理解 → 触发 → 工具 → 记忆 → 反馈
* 主动触发徽标：时间触发 / 场景触发一目了然
* 浏览器中文语音朗读（Web Speech API）
* 长期记忆面板实时更新：物品位置、健康日志
* 页面底部标注五大验证点：第一视角 / 语音交互 / 实时感知 / 随身陪伴 / 轻量反馈

## 在线部署（生成可访问链接）

* **GitHub Pages**：把 `web/` 内容推到仓库 Pages 分支
* **Vercel**：`vercel` 部署静态目录
* **Netlify**：直接拖拽 `web/` 文件夹上传

## 录视频建议

1. 用 OBS 或系统录屏录制浏览器窗口
2. 依次演示三个闭环，每步停在"反馈"轨迹上 1–2 秒
3. 穿插记忆面板变化特写（如服药记录写入）
4. 画外音按「痛点 → 交互 → Agent 决策 → 沉淀」讲解

## 逻辑校验（可选）

```powershell
node web/tests/agent_check.js
```

无需浏览器即可验证 Agent 核心逻辑（需要 Node.js）。
