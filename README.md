# 暖眸 · 居家养老 AI 眼镜智能体

> 看得见 · 记得住 · 靠得住

面向独居老人的第一视角随身智能体：以眼镜的"第一视角"感知现实，
以语音和轻量反馈完成交互，以持续记忆提供主动陪伴。

赛题方向：AI+眼镜 · 下一代个人智能终端原生智能体
重点验证：第一视角 / 语音交互 / 实时感知 / 随身陪伴 / 轻量反馈

---

## 一、作品简介

给 60–80 岁独居老人配一个"看得见、记得住、靠得住"的随身智能体。
典型用户是 68 岁独居、轻度健忘的王奶奶。

**核心能力**

| 功能 | 触发方式 | 说明 |
| --- | --- | --- |
| 记忆找物 | 老人语音提问 | 第一视角记忆物品位置，随问随答，找到后复核更新 |
| 用药提醒 + 视觉确认 | 时间触发 | 主动提醒 → 识别药盒 → 确认服药 → 写入健康日志，漏服升级通知家人 |
| 出门提醒 | 场景触发 | 识别走向门口，联动天气与室内状态（关火）提醒 |
| 跌倒检测与求助 | 异常触发 | IMU + 视觉双通道，语音二次确认，无回应自动联系家人 |
| 主动陪伴 / 健康日报 | 时间/情绪触发 | 低打扰陪伴，每晚给家人一条"今天都挺好" |

**原生智能体体现**：不是泛问答，而是感知驱动 + 主动触发 + 记忆沉淀的闭环。
每条主动消息都有触发原因和优先级，决策全程可回溯。

**产品形态说明**：网页端为初赛演示形态（便于评审直接复现）；正式产品为
「AI 眼镜 + 老人端 App + 子女端 App」，双端功能与界面构想见
[docs/暖眸-产品设计方案.md](docs/暖眸-产品设计方案.md) 第 9 章。

## 三、快速开始（初赛演示）

**真实 Agent 版（推荐：初赛要求“Agent 真实运行”）**

```powershell
cd app
py server.py
```

浏览器打开 http://127.0.0.1:8000 ，在「配置」页填入你自己的 AI 服务 Key
（OpenAI / DeepSeek / 通义千问 / Ollama 等兼容接口均可），即可用摄像头、
照片、语音真实运行三个闭环。详见 [app/README.md](app/README.md)。

**Web Demo（概念演示版，无需 Key，规则版 Agent）**

```powershell
cd web
python -m http.server 8000
```

浏览器打开 http://localhost:8000 （Chrome/Edge 效果最佳），
或直接双击 `web/index.html`。包含三个闭环：

1. 记忆找物：老人问"我的老花镜呢？" → 检索记忆 → 语音回答 → 复核更新
2. 用药提醒：08:00 主动开口 → 视觉确认药盒 → 确认服药 → 写入健康日志
3. 出门提醒：识别走向门口 → 天气 + 关火联动提醒 → 确认后状态更新

**Python 版 Demo（校验与扩展）**

```powershell
cd demo
py main.py --scene find_glasses --check
py main.py --scene medication --check
py main.py --scene door_reminder --check
```

## 四、技术路线

| 层 | 方案 |
| --- | --- |
| 端侧感知 | 眼镜摄像头 + IMU；轻量模型（场景/物体/人形），或 GPASS 端侧 API |
| 多模态理解 | GPT-4o / 千问 VL（复杂场景、OCR） |
| 语音 | 支持方言的 ASR（讯飞/通义）+ 慢速清晰 TTS |
| Agent 编排 | 蚂蚁百宝箱 + GPASS（镜腿触控/语音/摄像头 API）；备选 LangGraph |
| 知识库 | 用药常识、老年健康问答（RAG，明确不做诊断） |
| 部署 | 端云协同：实时性高的端侧，理解与推理云端，家人通知走云推送 |

## 五、数据与合规边界

- 数据来源：用户与家属授权采集；演示用剧本模拟数据
- 隐私：本地优先、最小必要、人脸模糊、加密存储、可删除
- 合规：个人信息保护法；不做医疗诊断（"提醒工具"定位）；
  跌倒求助为通知辅助而非急救保障；采集有指示灯并可随时撤回
